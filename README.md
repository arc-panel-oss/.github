# arc-panel-oss/.github

The organization profile and default community files of [ArcPanel](https://arcpanel.org).

| File                        | Purpose                                                                           |
| --------------------------- | --------------------------------------------------------------------------------- |
| `profile/README.md`         | The profile shown on [github.com/arc-panel-oss](https://github.com/arc-panel-oss) |
| `CODE_OF_CONDUCT.md`        | Contributor Covenant 2.1                                                          |
| `CONTRIBUTING.md`           | How to help; pull requests after an accepted issue                                |
| `SUPPORT.md`                | Where to ask questions and find help                                              |
| `SECURITY.md`               | How to report a vulnerability privately                                           |
| `pull_request_template.md`  | The default pull request description                                              |
| `ISSUE_TEMPLATE/config.yml` | Contact links on the "New issue" page                                             |

GitHub uses these files in every repository of the organization that has no file of the same kind. A repository's own file takes precedence.
