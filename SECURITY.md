# Security policy

Please report a vulnerability privately through a GitHub Security Advisory on the affected repository (**Security** tab → **Report a vulnerability**). If you are not sure which repository is affected, use [arc-panel-oss/arcpanel](https://github.com/arc-panel-oss/arcpanel/security/advisories/new).

Include a description of the issue, the versions you tested, the steps to reproduce it and what you expected. We answer within 3 working days.

Do not open a public issue or post about it elsewhere before the advisory has been published and a fix has been released.

A repository may have its own `SECURITY.md` with more detail; it takes precedence over this one.
