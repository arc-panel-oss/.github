<p align="center"><strong>The open-source control panel for Linux web servers.</strong></p>

Web domains, DNS, mail, databases, SSL and backups, plus Node.js and Docker apps — from one dashboard and one command line. Free to use, free to change, for everyone.

## Install

On a fresh server, as root:

```bash
wget https://arcpanel.top/install.sh
sudo bash install.sh
```

Debian 12 / 13 · Ubuntu 22.04 / 24.04 / 26.04 LTS · amd64

## What you get

- **Hosting in one place:** web domains on Nginx or Apache, DNS zones, mail with webmail, MariaDB, MySQL and PostgreSQL databases.
- **SSL by default:** Let's Encrypt certificates, issued and renewed for you.
- **Backups:** scheduled full backups and incremental backups with Restic.
- **Apps:** Node.js applications and Docker apps next to your sites.
- **Automation:** a REST API, a TypeScript SDK and the `arc` command line tool.
- **Security:** firewall and Fail2ban managed from the panel.

Every feature is in the free download. No plan unlocks code.
